# 4090 PTR 端到端验证与延迟基准（2026-09-26）

> 环境：4090 本地（127.0.0.1，排除网络 RTT）；文档为 PTR 冷却泵设备运行与维修手册（真实核电设备文档）。
> 本文是简历条 6 新口径数字的唯一来源。原始材料为 4090 会话输出，2026-09-27 整理落盘。

## 一、知识图谱构建

**三阶段**：

1. 文档解析分块（42.74s）：DeepDOC 解析 docx → 116 个 raw chunks → bge-base embedding → 写入 ES
2. 第一次 GraphRAG（失败，35s）：模型实例名 qwen38-local 未找到，全部 CONNECTION_ERROR，17 个 chunk 全部失败
3. 第二次 GraphRAG（成功，1310.67s ≈ 21 分 51 秒）：116 chunks 合并为 17 个 LLM 抽取单元，每 chunk 1 次 gleaning（首轮抽取→问遗漏→补充一轮）；17 单元全部完成，累计 **979 nodes / 719 edges**；子图合并：图转换 1700 chunks（90s）→ 写 ES（8.5s）→ graph ready

**成本**：LLM 总消耗约 90 万 tokens；单 chunk 抽取统计见附录 A。

## 二、检索与问答对比

| 测试 | 结果 |
|---|---|

## 三、延迟基准（多次实测）

**配置**：LLM = Qwen3.8-27B-AWQ-INT4，vLLM TP2（max_num_seqs=8、gpu_mem 0.92、prefix_caching/chunked_prefill on、enable_thinking=false）；RAGFlow Chat：top_k=1024 / top_n=6 / similarity_threshold=0.1 / vector_similarity_weight=0.3。

| 测试项 | 平均延迟 | 目标 | 结果 |
|---|---|---|---|
| 纯 LLM 短回答（max_tokens=32） | 470~527ms | - | - |
| 纯 LLM 长回答（max_tokens=256） | 3516~3532ms | - | - |
| vLLM 流式 TTFT | 136~174ms | - | - |
| 向量检索（无 KG） | 563ms（365~882） | - | - |
| KG 检索 | 1240ms（1169~1534） | - | - |
| E2E 简单问答（非流式） | 5790ms | ≤2000ms | 2.9× 超标 |
| E2E 复杂问答（非流式） | 15383ms | ≤5000ms | 3.1× 超标 |
| **E2E 简单问答（流式 TTFT）** | **899ms** | **≤2000ms** | **达标 ✅** |
| **E2E 复杂问答（流式 TTFT）** | **938ms** | **≤5000ms** | **达标 ✅** |

## 四、耗时分解

**简单问答（流式，总 ~3s）**：向量检索 563ms（19%）+ prompt 构造调度 186ms（6%）+ vLLM TTFT 150ms（5%）+ LLM 生成 ~2100ms（**70%**）

**复杂问答（流式，总 ~27.6s）**：检索 563ms（2%）+ prompt 287ms（1%）+ TTFT 150ms（0.5%）+ LLM 生成 ~26632ms（**96.5%**，200+ streaming chunks）

## 五、关键结论

1. **瓶颈是 LLM 生成不是检索**：生成占简单 70% / 复杂 96.5%；vLLM 72~75 tok/s 在 27B AWQ-INT4+TP2 属正常水平，问题是生成 token 量大
2. **检索不是瓶颈**：向量 563ms、KG 1240ms 均合理，top_n=6 上下文可控
3. **流式 TTFT 是达标路径**：按"用户看到第一个字"定义时效，流式模式已双达标
4. KG 检索质量显著优于纯向量（+40%），且命中关键参数表——GraphRAG 价值在真实业务文档上得到量化

## 六、优化方案（P0~P3，当时未落地）

| 优先级 | 优化项 | 预期 | 难度 |
|---|---|---|---|
| P0 | 启用流式（stream: true） | TTFT ~0.9s 双达标 | 低 |
| P0 | 限制 max_tokens（简单 128~256） | 简单总时长 5.8→~3s | 低 |
| P1 | system prompt 简洁化；top_n 6→3~4 | 减少生成与 prefill | 低 |
| P2 | vLLM max_num_seqs 8→16；小模型（14B）处理简单问答 | 简单 ~1.5s | 中 |
| P3 | GPU1+2 部署第二模型，大小分流（简单 14B/复杂 27B） | 架构级 | 中 |

三管齐下预估：简单 ~2~2.5s、复杂 ~5~6s。**落地复测在 4090 测试清单 T2。**
