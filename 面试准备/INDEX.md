# 面试准备 · 学习地图（入口文件）

> 目标：把分散的材料变成以**问题为中心**的自测体系。
> 用法：每天 30~60 分钟——勾卡片、复述故事；答不上再去查阅层定位。
> 简历在本文件夹（精简版/详细版）。调研文档在 `f:\byh\知识库\`，测试报告在 `f:\byh\测试报告\`，源码在 `f:\byh\源码\`。
> 全局导航见 `f:\byh\材料地图.md`。

## 学习顺序（建议）

1. **第一周**：三个核心故事（核心故事/）脱稿复述 → 每个故事 5 分钟讲给空气听
2. **第二周起**：知识点卡片按编号顺序自测（02_知识点问答/），配合自测题库（05_自测题库.md）
3. 全程：新测试结果出来 → 更新对应卡片和故事里的数字

- 每张卡片格式统一：一句话答案 → 2 分钟展开 → 深挖自测问答 → 项目数字 → 来源链接

- 答不上回查：先去知识库对应目录，再去源码对照行号
