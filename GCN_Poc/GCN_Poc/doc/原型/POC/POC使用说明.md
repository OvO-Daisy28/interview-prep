# 文件活化平台 — 使用说明与演示脚本

## 一、启动方式

- 双击 `POC/index.html` 即可运行（推荐 Chrome / Edge 浏览器）。
- **完全离线**：所有前端库已本地化到 `vendor/` 目录，无需联网、无需安装任何环境、无需启动服务。
- 建议演示分辨率 1920×1080，浏览器缩放 100%。

## 二、数据来源说明（向客户讲解口径）

本 POC 的全部演示数据来自真实工程文件，由构建脚本自动抽取（`tools/build_mock_data.py`）：

| 演示数据 | 真实来源 |
|----------|----------|
| 文档目录树（94 个章节节点，四级） | 《PTR冷却泵设备运行与维修手册.docx》真实目录 |
| 79 个内容块（0.4安全 / 1.2详细描述 / 2.3故障处理 / 3.7回装 全量，已去重） | 手册正文真实段落 |
| 12 条技术参数（640m³/h、36m、1480r/min、90kW…） | 手册真实参数 |
| 故障诊断表 / 螺栓力矩表 / 备件清单 / 设备代码清单 | 手册真实表格（共 61 张表格中选取） |
| DMC 编码（HPR1000-A-45-20-0000-00A-xxx） | 《PTR冷却泵分解数据结构.xlsx》真实编码 |
| 手册生成模板章节框架 | 《PTR冷却泵设备期望生成技术资料.docx》目标结构 |

> 说明：AI 处理过程（语义切分、知识抽取、GraphRAG 问答、智能建议）为预置结果 + 流式动画模拟，体现的是产品形态与交互设计；真实系统中由大语言模型完成。

## 三、演示脚本（推荐时长 15~20 分钟）

### 1. 工作台（30 秒）
- 讲解：项目全景 —— 已导入 5 份文档、79 个内容块、知识图谱 31 实体；点击流程图任意环节跳转。
- 顶部步骤条贯穿"解析→入库→知识化→治理→生成→AI辅助"主线。

### 2. 内容解析（4 分钟）⭐
- **文档导入**标签页：展示批量导入列表；指出扫描版 PDF 的 `OCR 98.6%` 标签（验收线 98%）；点击"断点重试"演示失败恢复；点击"批量导入文档"模拟进度。
- **解析任务调度**标签页：讲解三引擎协同（传统程序 → LLM → 知识库引擎），下方日志滚动展示 LLM 正在处理的语义任务。
- **解析结果与 AI 审核**标签页（重点）：
  - 顶部准确率面板：AI 提取 79 条、初始准确率 95.8%（验收线 95%，已预置 3 条人工修正）。
  - 左侧目录树点选 `1.2 详细描述` / `3.7 回装`：中间是**手册原文**，右侧是 **AI 提取的内容块**（带内容类型、通用/专用、置信度、DMC 编码）。
  - 找一条"待审核"的内容块 → 点【确认】，观察准确率面板数字变化；再点【修正】改一个字保存 → 准确率实时重算（讲解：人机差异记录用于模型优化；审核状态与内容数据库页实时共享）。
  - 切到**参数**子标签：顶部高亮"复合参数拆分"示例（需求点名场景：一句拆两条）；参数表含单位/分类/所属部件/适用条件（入口压力的"表压基准(g)"）。
  - 切到**表格**子标签：依次展示故障诊断表（现象-原因-措施三元组）、螺栓力矩表、备件清单；强调"保留表格与章节上下文关联""仅解析清单内表格类型（需求导向）"。

### 3. 规则梳理与建模（2 分钟）
- 四个分析面板：章节聚类（3 类设备手册的章节框架）、相似度 TOP 清单（≥85% 阈值，通用内容候选）、术语词频图、切分粒度建议表。
- 点击【输出规则草案】：展示五类规则（章节框架/解析/生成/审查/权限）→【提交甲方评审】。
- 口径："规则草案在存量文件导入后提交甲方首轮评审，确认后作为拆解执行依据"。

### 4. 内容数据库（2.5 分钟）
- 组合检索：内容类型选"注意事项"+关键词"联轴器" → 检索，展示响应时间。
- 点击任意行打开详情抽屉：DMC 编码、显式关联关系（引用/从属/顺序/交叉引用）、版本时间线。
- 点击【版本对比】：V1→V2 双栏 diff，新增绿色高亮；演示【回退到此版本】。
- 点击【跨设备参数对比】：PTR/RRI/CEF 三台泵同类参数并列。
- 指出"通用"标记行的抽屉底部警告：已被 3 份手册引用 → 引出治理页。

### 5. 知识库与知识图谱（3 分钟）⭐
- **知识图谱**标签页：力导向图（六类实体六种颜色）；点击"轴承发热"节点 → 右侧显示属性、置信度 0.93、来源章节、关联关系链；顶部切换"设计/制造/安装调试/运行"时序版本，图谱按阶段过滤。
- **语义检索与推理**标签页：
  - 点示例"轴承发热怎么处理？" → GraphRAG Local 模式流式作答，右侧证据链（来源+置信度+时序节点）。
  - 点示例"对比一下全厂泵类设备的常见故障模式" → GraphRAG Global（社区发现）全局汇总。
- **知识库管理**标签页：知识分类树 + 节点属性（知识ID/来源/版本/状态）。

### 6. 内容治理（2 分钟）
- **术语标准化**：字典表（机械密封↔机封、联轴器↔联轴节）；右侧"入库自动检测"3 条 → 点【标准化替换】，提示原文留痕。
- **数据质量检查**：点【立即运行检查】→ 报告：4 类规则、错误/警告/提示分级（如两处流量值不一致、图纸关联缺失）。
- **变更管理**：填变更原因 →【影响范围分析】→ 展示通用块 CB-0021 影响 3 份手册（2 份需重新生成、1 份自动同步）。

### 7. 手册生成（4 分钟）⭐ 演示高潮
- **模板管理**标签页：左侧两套模板（核级/非核级）；右侧模板编辑器展示章节-槽位树，指出"附件"行的条件化规则"核级设备包含"。
- 点击【使用该模板生成手册】→ 向导：模板 × PTR冷却泵 × Word →【开始智能组装】。
- 观看组装动画：检索内容块 → 参数槽位填充 → 条件化裁剪 → 编号编排 → 目录/有效页生成。
- **在线预览**：A4 版式手册 —— 封面（真实设备编码/核安全等级）、自动目录、各章内容（真实参数表、故障表、力矩表、备件清单）、2 处黄色高亮"待人工补充"槽位、有效页清单。
- 勾选"预览微调模式"：对段落执行上移/编辑 →【回写数据库】。
- 点击【导出 Word】→ **真实下载 .docx 文件**，现场用 Word 打开（可继续编辑）。
- 口径：补一句"生成 → 审校 → 修正 → 定稿闭环"（提交审校按钮）。

### 8. AI 辅助编辑（2 分钟）
- 点击【AI 智能分析】→ 右侧逐条流式生成 4 类建议：
  1. 术语标准化（机封→机械密封）；2. 参数合理性（45N·m 低于常见范围）；3. 完整性提示（建议引用安全注意事项）；4. 知识召回（跳动允差 0.05mm）。
- 对建议 1、3 点【一键采纳】→ 左侧文本实时改写；讲解采纳反馈计数。
- 点击【运行一致性/完整性审查】→ 智能审查结果。
- 底部知识检索：输入"密封环跳动允差"→ 检索 →【插入引用】。

### 收尾话术
"以上全链路演示了采购文件内容的'解析—入库—知识化—治理—生成—AI辅助'数字化闭环。所有数据来自太平岭 PTR 冷却泵真实手册，所有 AI 结果均有人工复核环节，符合需求中的准确率与可追溯要求。"

## 四、常见问题

| 问题 | 回答口径 |
|------|----------|
| 数据是真的吗？ | 解析结果全部来自 PTR 真实手册，可用原 docx 对照；AI 处理过程为模拟演示 |
| 能解析扫描件吗？ | 导入列表中的扫描版 PDF 展示了 OCR 能力入口（98.6%，验收线 98%） |
| 支持别的设备类型吗？ | 模板管理中有"非核级设备简化模板"；规则梳理页展示了 3 类设备手册的聚类结果 |
| 安全吗？ | 纯离线演示；真实系统部署于甲方内网，RAGFlow 本地化 |
