## 四、关键配置（可复现）

### bge-gpu 容器启动

```bash
docker run -d --name bge-gpu \
  --gpus all \
  -e CUDA_VISIBLE_DEVICES=2 \
  --network docker_ragflow \
  --restart unless-stopped \
  bge-embedding:gpu-v2
```

### bge-embedding:gpu-v2 镜像 build（在 131）

```dockerfile
FROM docker.m.daocloud.io/library/python:3.11-slim
COPY uv /usr/local/bin/uv
RUN chmod +x /usr/local/bin/uv && uv venv /opt/venv && \
    VIRTUAL_ENV=/opt/venv uv pip install --index-url https://pypi.tuna.tsinghua.edu.cn/simple sentence-transformers fastapi uvicorn requests psutil
COPY model /data/model
COPY my_bge_flask.py embedding_proxy.py /app/
ENV PATH=/opt/venv/bin:$PATH
WORKDIR /app
EXPOSE 18001 18002
CMD ["sh","-c","/opt/venv/bin/python my_bge_flask.py & /opt/venv/bin/python embedding_proxy.py"]
```

### RAGFlow .env 关键改动（4090 /root/ragflow/docker/.env）

```
DEVICE=gpu
RAGFLOW_IMAGE=infiniflow/ragflow:v0.26.1
SVR_WEB_HTTP_PORT=9388
ES_PORT=9200
EXPOSE_MYSQL_PORT=5455
MINIO_PORT=19000
MINIO_CONSOLE_PORT=19001
REDIS_PORT=26379
SVR_WEB_HTTPS_PORT=19443
```

### RAGFlow 改密码（正确方式）

```bash
ssh root@10.148.4.21 "docker exec docker-ragflow-gpu-1 /ragflow/.venv/bin/python3 -c \"
import base64
from werkzeug.security import generate_password_hash
from api.db.db_models import DB
b64 = base64.b64encode('明文密码'.encode()).decode()
h = generate_password_hash(b64)
DB.execute_sql(\\\"UPDATE user SET password='%s' WHERE email='xxx'\\\" % h)
\""
```

### RAGFlow 登录密码坑（原理）

- 前端：`base64(密码)` → `RSA加密` → 提交
- 服务端：`decrypt()` 得到 base64 串 → `check_password_hash(DB密码, base64串)`
- DB 必须存：`generate_password_hash(base64.b64encode(明文密码))`

## 五、4090 网络结构性限制（最重要的坑，单独详述）

**事实**：4090 容器+宿主机对持续大文件下载**普遍卡死**。
- pip download：卡死（urllib3 keep-alive 被掐，吞吐 0）
- uv install：4090 上卡死（131 上不卡，因为网络环境不同）
- curl 短请求：能通（HEAD 请求 200）
- docker pull 走 mirror：能下
- docker save relay（131→本机→4090）：能下

**根因**：4090 是共享机，网络对持续大文件传输掐断（具体机制未知，可能是防火墙/QoS）。

**铁律**：
1. **不要在 4090 上直接 pip/uv 装大包**（torch、model 等）
2. 大文件只走 docker pull（daocloud mirror）或 docker save relay
3. 搬运 model 等非 docker 产物时，打进镜像再 docker save relay
4. build 镜像在 131 做（131 网络好），buildkit 的 `FROM` 必须加 daocloud 前缀

## 九、核心教训（给后来的自己）

1. **不确定先验证，别急着动手**——给 RAGFlow 容器装 GPU torch 白干半天，就是没先查清 embedding 架构
2. **4090 网络特殊**——大文件只能 docker pull / docker save relay，其他都卡
3. **撞墙后复盘再换方案**——别盲目切下一个方案，先想清根因
4. **配置源要用已验证的**——别用版本不明的本地源码，用线上跑通的
5. **密码加密链路要搞清**——RAGFlow 前端 base64→RSA，DB 存 base64 的 hash
6. **容器改动要固化进镜像**——否则重建容器丢失修复
7. **共享机要注意重启策略**——`--restart unless-stopped` 保证服务自恢复
