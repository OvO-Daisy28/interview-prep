# OCR 校对界面重设计（MinerU 风格三栏）

日期：2026-08-06
状态：已获用户批准
范围：`js/pages/parse.js` 的「扫描件 OCR 校对」tab + `css/main.css` 新增样式

## 背景

现有 OCR 校对 tab 是「左占位图 + 右表格」的简单布局，校对体验差。参考内网文档解析预览页（MinerU 风格，http://10.126.2.131:8010/web/detail.html）重做：三栏布局 + PDF 框选 + 详情卡片双向联动。

## 关键决策（用户已确认）

1. **形态**：留在 parse 页的 Tab 内，tab 内部做三栏布局（不做全屏独立页）
2. **中间预览**：CSS 仿真扫描页 + 彩色 bbox 框选（POC 无真实扫描图）
3. **左侧栏**：复用共享 `tocTree` 文档目录树，点章节跳到对应扫描页

## 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 工具条: 文档名 │ 识别N·已确认·待校对·准确率 │ 只看待校对☐ │ 保存 导出 │
├──────────┬───────────────────────────────────┬───────────────┤
│ 目录树    │   仿真扫描页（A4比例纸张）          │ 筛选chips      │
│ (tocTree)│   灰条模拟文字行/表格网格线          │ 条目卡片流      │
│          │   彩色bbox框选（按状态着色）         │ (内联修正)      │
│          │   缩放 −/100%/+ │ 翻页 ‹ n/N ›    │               │
├──────────┴───────────────────────────────────┴───────────────┤
│ 说明: 修正差异入「AI结果与人工修正差异库」，用于模型优化（验收线≥95%） │
└──────────────────────────────────────────────────────────────┘
```

## 组件设计

### 数据（mock 扩展）

`ocrPages` 每条目扩展字段：
- `bbox: [x1, y1, x2, y2]` 归一化坐标（0~1，相对页宽/页高）
- `type`：参数 / 段落 / 表格行
- `chapter`：关联 tocTree 章节 num（用于目录树跳转）
- `rows`（页级）：仿真页文字行布局（每行 y 坐标与宽度比例），表格区标记网格线

页数从 2 页扩到 4~6 页，使翻页、目录跳转有意义。

### 中间仿真页

- 白底 A4 比例"纸张"（CSS），页眉显示页码
- 灰色圆角条模拟文字行，表格区域画网格线
- 每条目叠加 bbox 框选，按状态着色：**待校对=琥珀/红、已确认=绿、已修正=蓝**；框上小标签显示类型+置信度
- 底部控件：缩放（− / 100% / +，三档）与翻页（‹ 页码/总页 ›）
- 点框选 → 选中对应右侧卡片并滚动定位

### 右侧卡片流

- 顶部 chips 筛选：全部 / 待校对 / 已修正 / 已确认（带计数），与顶栏「只看待校对」checkbox 等价保留其一（选 chips）
- 卡片内容：位置 loc、类型、置信度 pill、状态 tag、识别文本
- **内联修正**：点「修正」卡片文本变 textarea + 保存/取消（替代原 ElMessageBox.prompt）
- 点卡片 → 中间跳到该条目所在页，框选高亮 + 滚动定位
- 确认/修正操作沿用现有 `can('approve')` / `can('edit')` 权限控制

### 顶栏工具条

文档名 + 统计徽标（识别 N 条 · 已确认 · 待校对 · 准确率%）+ 保存、导出演示按钮。原顶部 warning alert 内容压缩进底部说明条。

## 双向联动

- 状态：`ocrSelId`（当前选中条目 id）、`ocrPage`（当前页）
- 卡片 → 预览：点击卡片设 `ocrSelId`，跳页，`nextTick` 后框选高亮（描边加粗 + 阴影），纸张滚动使框选居中
- 预览 → 卡片：点击框选设 `ocrSelId`，卡片列表滚动到对应卡片并高亮

## 样式

`main.css` 新增 `ocr-` 前缀类：`ocr-layout`、`ocr-toc`、`ocr-stage`、`ocr-paper`、`ocr-line`、`ocr-grid`、`ocr-box`（+状态修饰）、`ocr-cards`、`ocr-card`（+状态修饰）、`ocr-chip` 等。沿用现有青琥珀色板变量（--np-*）与 panel 风格。

## 边界与非目标

- 不改共享 store、不动其他 tab
- 不做真实图片加载、不做框选手动拖拽编辑（POC 演示不需要）
- 保存/导出为演示入口（ElMessage 提示）

## 校验

POC 无自动化测试。实现后用本地 HTTP 服务 + 浏览器实际打开页面，核对：三栏布局、chips 筛选、双向联动、内联修正、翻页与缩放均正常。
