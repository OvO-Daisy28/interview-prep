## 二、诚实前提（评分口径）

POC 的 AI 输出为**预置结果 + 流式动画模拟**（按《POC 方案设计 §3.3》），非真实大模型调用：
- §3/§7/§9/§124/§125/§185/§187/§192/§193 的 **AI 结果**为模拟，但**审核/交互 UI 全部可操作**（确认/修正/采纳/问答/检索真实响应）→ 满足 §202「可操作、可运行系统演示」。
- §168 组装从 PTR 真实手册抽取的内容块组装，可运行，非真实 DB 查询。
- 真实系统部署时由大模型 + 后端完成，POC 演示的是产品形态与人工复核闭环（口径已在《POC 使用说明》写明）。

## 三、15 分钟现场演示脚本（按 ▲ 项串成动线）

**总时长 15 分钟**，每步标注对应 ▲ 编号，全程可操作运行。建议双击 `POC/index.html` 启动后按序操作。

### 第一段：内容解析（4 分钟）— ▲1/2/3/4 + §68/69/124/125
1. **工作台**（30s）：点顶部阶段条「内容解析」进入。讲：闭环起点。
2. **文档导入**（30s）：导入 tab，多级目录树 + 批量导入列表 + 批量操作。点「批量导入」演示进度 → 完成。
3. **解析结果与 AI 审核** tab（3 分钟）⭐：
   - 左侧目录树点 `1.2 详细描述` → 展示四级章节树 **▲1 §68**。
   - 展开「解析元素清单」→ 段落/表格/图片/警示框 + 页码 + 位置 **▲2 §69**。
   - 切「参数」子标签 → 复合参数拆分示例 + 参数表(置信度) **▲3 §124**。
   - 切回「内容块」→ 原文(中) vs AI 提取(右)对照 + 逐条【确认】【修正】 + 顶部准确率横幅 95.8% **▲4 §125**。
   - 点一条待审核→【确认】，观察准确率实时变化。

### 第二段：知识库与图谱（4 分钟）— ▲5/6/7/8/9 + §74/75/78/85/88
4. **知识库管理** tab（1 分钟）：左分类树(设备/参数/操作/故障/部件/标准知识) **▲5 §74**；右知识节点详情(ID/类型/标题/内容/来源/创建/更新/状态) **▲6 §75**。
5. **实体抽取审核** tab（1 分钟）：LLM 抽取对照表 → 逐条确认 → 并入图谱 **▲7 §78**。
6. **知识图谱** tab（1.5 分钟）：力导向图；顶部切「设计/制造/安装调试/运行」时序版本，图谱按阶段过滤 **▲8 §85**；点节点看属性+置信度+来源。
7. **语义检索与推理** tab（30s）⭐：点示例「轴承发热怎么处理？」→ GraphRAG 流式作答 + 证据链(来源+置信度+时序) **▲9 §88**。

### 第三段：数据底座（2.5 分钟）— ▲10/11/12/13 + §130/134/135/142
8. **数据模型→扩展字段管理**（1 分钟）：选设备类型→核心字段(只读) + 扩展字段(增删) **▲10 §130**。
9. **内容数据库**（1.5 分钟）：12 维检索表 **▲11 §134**；关键词输入「联轴器」→检索→「命中 N 条 · 响应 Nms」 **▲12 §135**；点行打开详情抽屉→版本对比/回退；若为通用块点「模拟通用块变更」→触发生成页红条（联动到第四段）**▲13 §142**。

### 第四段：治理 + 生成（4 分钟）— ▲13/14/15/16 + §142/145/161/168
10. **内容治理→术语标准化**（1 分钟）：字典表(机械密封↔机封) + 入库检测 + 标准化替换 **▲14 §145**；切「变更管理」→填变更原因→「影响范围分析」→ 3 份手册受影响 **▲13 §142**。
11. **手册生成→模板管理**（1 分钟）：模板列表 + 编辑器(章节树+槽位+条件化规则) **▲15 §161**。
12. **手册生成→生成向导→开始智能组装**（2 分钟）⭐：组装动画→A4 预览(封面/目录/参数表/故障表/有效页)→【导出 Word】真实下载 .docx **▲16 §168**。

### 第五段：AI 辅助编辑（0.5 分钟）— ▲17/18/19/20 + §185/187/192/193
13. **AI 辅助编辑**（30s）：点【AI 智能分析】→ 四类建议：术语标准化 **▲17 §185**、完整性提示 **▲18 §187**；一键采纳。底部知识检索：输入「密封环跳动允差」→检索→【插入引用】 **▲19 §192 / ▲20 §193**。

### 收尾（15s）
"以上 16 个 ▲ 项现场可操作演示完成（另 4 项 AI 辅助同屏可见），全部数据来自太平岭 PTR 冷却泵真实手册，AI 结果均有人工复核环节，符合准确率与可追溯要求。"
